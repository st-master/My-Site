🛠️ Git push拒否（non-fast-forward）の対処法

Q. git pushしたら non-fast-forward エラーが出た場合の対処は？

A. git pull --rebase を実行する

リモート（GitHub上）の変更がローカルより先行しているため、以下のコマンドで変更を取り込んでから再度 push を行います。

git pull --rebase origin main
git push origin main
